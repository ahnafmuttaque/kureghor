# কুঁড়েঘর ফাউন্ডেশন (Kureghor Foundation) — আধুনিক Next.js ওয়েব পোর্টাল

একটি সম্পূর্ণ অরাজনৈতিক, অলাভজনক ও পাবলিক বিশ্ববিদ্যালয়ের শিক্ষার্থীদের দ্বারা পরিচালিত মানবিক সংগঠন **কুঁড়েঘর ফাউন্ডেশন** (কুঁড়েঘর অ্যাসোসিয়েশন)-এর প্রাতিষ্ঠানিক ওয়েব প্ল্যাটফর্ম।

এই প্ল্যাটফর্মটি প্রস্তুত করা হয়েছে **[আস-সুন্নাহ ফাউন্ডেশন](https://assunnahfoundation.org/)** এবং **জাগো ফাউন্ডেশন**-এর স্বচ্ছতা ও দায়বদ্ধতা কাঠামোর অনুপ্রেরণায়, `code.html`-এর আধুনিক কালার প্যালেট, টাইপোগ্রাফি ও উপাদানভিত্তিক আর্কিটেকচার বজায় রেখে।

## 🌟 মূল বৈশিষ্ট্যসমূহ (Key Highlights)

### ১. প্রাতিষ্ঠানিক আর্থিক স্বচ্ছতা ও অডিট লেজার (As-Sunnah Model)
* **শূন্য প্রশাসনিক ব্যয় (0% Administrative/Salary Cost):** কোনো নির্বাহী বেতন বা রাজনৈতিক চাঁদা নেই।
* **তহবিল বণ্টন অনুপাত:** ৯২% সরাসরি মাঠপর্যায়ে সামগ্রী ও সেবায়, ৫% শিক্ষার্থী পরিবহন ও মাঠ সমন্বয়, ৩% আইটি ও গেটওয়ে খরচ।
* **ডোনাট চার্ট ও অডিট ট্র্যাকিং:** প্রতিটি আয়-ব্যয়, ভাউচার ও নিরীক্ষা প্রতিবেদনের উন্মুক্ত ডিজিটাল ডিসপ্লে।

### ২. লাইভ কুইক অনুদান পোর্টাল (Interactive Donation Widget)
* এককালীন ও মাসিক অনুদানের ফ্রিকোয়েন্সি সুইচার।
* খাত নির্বাচন: শিশু শিক্ষা, বিনামূল্যে চিকিৎসা, বৃক্ষরোপণ, সাধারণ কল্যাণ তহবিল।
* বিকাশ, নগদ ও রকেটের রিয়েল-টাইম কপি বাটন ও রেফারেন্স নির্দেশিকা (`ডাকনাম জন্মসাল`, যেমন: `Raju 2003`)।
* ওয়ান-ক্লিক হোয়াটসঅ্যাপ ট্রানজেকশন ভেরিফিকেশন ও ডিজিটাল রসিদ সেবা।

### ৩. উপাদানভিত্তিক আধুনিক আর্কিটেকচার (Component-Based Architecture)
* **Next.js 14 App Router** সহ সম্পূর্ণ সার্ভার-সাইড স্ট্যাটিক জেনারেশন (SSG - 20টি স্ট্যাটিক পেজ প্রিরেন্ডারড)।
* **Tailwind CSS ৩.৪** সহ কাস্টম কালার সিস্টেম (ডিপ ফরেস্ট গ্রিন `#004c22`, ভাইব্রেন্ট অরেঞ্জ/অ্যাম্বার `#fe932c` / `#904d00`, সফট সারফেস `#faf8ff`)।
* **Google Fonts:** `Hind Siliguri` (বাংলা ফন্ট), `Plus Jakarta Sans`, এবং `Inter`।
* **Lucide React Icons** এবং **Material Symbols Outlined**।

### ৪. সর্বোচ্চ এসইও অপ্টিমাইজেশন (SEO & Social Sharing Ready)
* **JSON-LD Schema Markup:** `Organization`, `NGO`, `NonProfitOrganization`, এবং `WebSite` স্কিমা সংযুক্ত।
* **ডায়নামিক মেটাডাটা:** প্রতিটি পেজের জন্য অপ্টিমাইজড Title, Description, Keywords, Canonical URL।
* **OpenGraph & Twitter Card:** ফেসবুক ও টুইটারে শেয়ারের জন্য প্রিভিউ কার্ড।
* **স্বয়ংক্রিয় সাইটম্যাপ ও রোবটস:** `/sitemap.xml` এবং `/robots.txt` জেনারেটর বিল্ট-ইন।

## 🚀 লোকাল সার্ভারে রান করার নির্দেশিকা (How to Run Locally)

### ১. ডিপেন্ডেন্সি ইনস্টল (যদি প্রয়োজন হয়):
```bash
npm install
```

### ২. ডেভেলপমেন্ট সার্ভার চালু:
```bash
npm run dev
```
ব্রাউজারে খুলুন: `http://localhost:3000`

### ৩. প্রোডাকশন বিল্ড ও স্ট্যাটিক এক্সপোর্ট টেস্ট:
```bash
npm run build
npm run start
```

## 🌐 ডিপ্লয়মেন্ট (Deployment)

প্রকল্পটি Vercel, Netlify, Cloudflare Pages বা যেকোনো Node.js / স্ট্যাটিক হোস্টিংয়ে সরাসরি ডিপ্লয় করার জন্য প্রস্তুত।
Vercel-এ ডিপ্লয় করতে গিট রিপোজিটরি কানেক্ট করলেই স্বয়ংক্রিয়ভাবে বিল্ড সম্পন্ন হবে।
